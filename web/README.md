# web — AI 가시성 대시보드

`data/history.jsonl` 을 굽어낸 `public/summary.json` 하나만 읽는 **정적 페이지**다.
빌드 스텝도, 외부 라이브러리도, CDN 요청도 없다. 차트는 SVG로 직접 그린다.

## 로컬 실행

```bash
node bin/serve.mjs
# → http://localhost:4178
```

이 서버 하나로 대시보드와 **실행 API**를 함께 제공한다. 측정·굽기를 브라우저에서
바로 실행하고 진행 로그를 실시간으로 볼 수 있다(터미널 명령 불필요).

읽기 전용으로만 띄우려면 정적 서버도 된다. 이때 `측정 실행` 탭은 안내만 표시한다.

```bash
python3 -m http.server 4178 --directory web/public
```

## 실행 API (bin/serve.mjs)

| 엔드포인트 | 하는 일 |
|---|---|
| `GET /api/status` | 설정 목록 · API 키 보유 여부(값은 노출 안 함) · 누적 측정 통계 |
| `GET /api/logs` | 진행 로그 SSE 스트림 (재접속 시 이전 로그 복원) |
| `POST /api/run` | `{kind: "quick"\|"run"\|"export", config: "<파일명>"}` |

**안전장치** — 로컬 전용 도구지만 최소한은 지킨다.

- `127.0.0.1` 에만 바인딩 (외부 접근 불가)
- 실행 가능한 명령은 화이트리스트 3개뿐. 사용자가 보낸 문자열이 셸 인자로 흘러가지 않는다
- `config` 는 `configs/` 안의 실제 파일명과 정확히 일치할 때만 허용 (경로 이탈 차단)
- 동시에 한 작업만 실행
- API 키는 보유 여부(true/false)만 응답하고 값은 절대 내보내지 않는다

## 키 없이 시험하기

`configs/demo-mock.json` 은 provider 가 `command` 인 가짜 모델(`scripts/mock-model.sh`)을
쓴다. API 키·비용 없이 수집 → 집계 → 대시보드 갱신까지 전 과정을 확인할 수 있다.

## 표기 원칙 (코드로 강제)

이 대시보드는 "작은 표본을 큰 데이터처럼 보이게 하지 않는 것"을 설계 목표로 둔다.

- **단일 종합 점수를 만들지 않는다.** 언급률·순위·점유율을 임의 가중치로 합치면 검증되지 않은 정밀도가 생긴다. 요약은 상태 라벨(높음/중간/낮음)로만.
- **퍼센트는 정수, 항상 `k/N` 병기.** `42.3%` 같은 표기는 없다.
- **미언급은 순위 통계에서 제외.** 최하위 순위로 치환하지 않는다.
- **"시장 점유율"이라 쓰지 않는다.** → "추적 질문군 내 응답 점유율".
- **인용을 제공하지 않는 모델은 `0%`가 아니라 `측정 불가`.**
- **측정 완결성(유효 응답률)을 KPI 급으로 노출한다.** 마케팅상 이득이 없는 지표를 숨기지 않는 것이 이 도구의 신뢰 근거다.
- 인용 출처를 "노출의 원인"으로 단정하지 않는다.
